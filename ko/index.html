지원

Mac에서 교사, 수업, 캠퍼스를 관리하고 시간표를 생성하고 내보낼 수 있습니다. 앱 계정 가입은 필요하지 않습니다.

무료 체험과 정식 버전

Mac 사용자별 앱 데이터에 대해 자동 시간표 생성에 성공한 20회를 무료로 제공합니다. 모든 캠퍼스와 계획이 횟수를 공유합니다. 실패, 취소, 실행 가능성 분석, 수동 편집 및 내보내기는 차감하지 않습니다. 일회성 앱 내 구입으로 자동 생성을 횟수 제한 없이 사용할 수 있으며 구독은 없습니다. 체험 종료 후에도 조회, 편집, 저장 및 내보내기를 사용할 수 있습니다.

설정 → 정식 버전에서 구입하거나 구입 항목을 복원하세요. 가격은 현재 App Store 지역에 따라 표시됩니다. 복원할 때는 원래 구입에 사용한 Apple 계정을 사용하세요.

저장과 백업

변경 사항은 Mac의 앱 데이터에 저장됩니다. 파일 → 시간표 파일 저장에서 완전한 .zzgkpk 백업을 정기적으로 보관하세요. Excel과 이미지는 조회 및 공유용이며 완전한 백업을 대신하지 않습니다.

시간표 파일을 열면 현재 캠퍼스의 작업 내용과 공유 교사 명단이 교체됩니다. 기존 작업을 먼저 저장하고 확인 메시지를 읽어 주세요.

시간표 생성

교사 가능 시간, 활성 교시, 수업 수, 합반 설정을 확인하세요. 배정되지 않은 수업이 있다면 실행 가능성 분석을 확인하세요. 계산을 취소하고 설정을 조정할 수도 있습니다.
