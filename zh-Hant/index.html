使用支援

在 Mac 上管理教師、課程和校區，產生並匯出課表。無需註冊應用程式帳號。

免費試用與完整版

每位 Mac 使用者的應用程式資料庫提供20次成功自動排課機會，所有校區與方案共用。失敗、取消、可行性分析、手動編輯和匯出均不計次。一次性 App 內購買即可解鎖不限次數的自動排課，無須訂閱。試用結束後仍可檢視、編輯、儲存和匯出。

在「設定 → 完整版」中購買或回復購買項目。價格以目前 App Store 地區顯示為準；回復購買時，請使用原先購買所用的 Apple 帳號。

儲存與備份

日常修改儲存在本機應用程式資料庫。建議定期透過「檔案 → 儲存課表檔案」保留完整的 .zzgkpk 備份。Excel 和圖片適合檢視與分享，不能取代完整備份。

開啟課表檔案會取代目前校區的工作內容及共用教師名冊。請先儲存現有內容，並閱讀確認提示。

排課

排課前請檢查教師可用時間、啟用節次、課程數量和合班設定。如有課程未排入，可查看可行性分析。計算過程中可取消，再調整設定。

取得協助

請寄信至 827868421@qq.com，或透過 GitHub Issues 回報。請說明應用程式與 macOS 版本、Mac 晶片類型、重現步驟、預期與實際結果。

請勿在公開回報中附上真實教師姓名、聯絡資料或含個人資訊的課表檔案；範例請使用虛構資料。您主動傳送的支援訊息用於處理您的請求。
